### 🚀 Featured Projects

**1. Contrastive Multimodal Product Search Engine**
- Built an end-to-end visual product search engine using YOLO, CLIP and BLIP-2.
- Fine-tuned CLIP using InfoNCE contrastive loss and implemented HNSW-based approximate nearest-neighbor search.
- Improved HR@15 from 0.5530 to 0.9374 on the DeepFashion benchmark.

**2. Multi-Engine ETL and Analytics Framework**
- Developed a Java-based ETL framework processing 3.46M NASA web log records.
- Implemented pipelines across MapReduce, Pig, Hive and MongoDB.
- Built a PostgreSQL-backed reporting layer for cross-engine benchmarking.

**3. Multicore Lock Benchmark Suite**
- Developed a C++ benchmarking framework comparing four synchronization primitives.
- Analyzed P99/P99.9 latency, cache/branch MPKI and fairness using Linux perf.
- Identified MCS lock advantages and a nearly 2× false-sharing performance penalty.

**4. OCR for Text Extraction and Verification**
- Built an offline multilingual OCR system using PHOCR, FastAPI and Qwen2.5-1.5B.
- Achieved CERs of 0.0008 (English), 0.0057 (Chinese) and 0.0039 (Japanese).
- Developed a Dockerized React–FastAPI application with automated testing.
